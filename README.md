# DataMeter (iOS 17+)

1. ارفع كل الملفات لمستودع GitHub عام (Public) بنفس المسارات.
2. Actions > Build IPA > Run workflow.
3. نزّل Artifact باسم DataMeter-ipa وفك الضغط للحصول على DataMeter.ipa.
4. ثبّته بـ Sideloadly، وفعّل Developer Mode على الآيفون.

غيّر PRODUCT_BUNDLE_IDENTIFIER في project.yml لاسم فريد قبل البناء.
